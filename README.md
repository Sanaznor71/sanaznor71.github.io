# Yasaman Hajnorouzali — Academic Website (Redesign)

This is a **static, multi-page academic website** inspired by the academic information architecture of Parnian Kamran's and Mahdis Rabbani's websites. It is independently styled and uses no external web fonts, libraries, or analytics.

## Pages
- `index.html`: academic introduction, selected research, publications, appointments
- `research.html`: detailed projects and research themes
- `publications.html`: reviewed publications and links to publisher records
- `experience.html`: research, teaching, and service
- `about.html`: academic background, education, and technical skills

All visual illustrations are original vector artwork created for this template; they are conceptual (not real experimental figures). Use your own photos, plots and on-road images to replace them as desired.

## Publish to GitHub Pages

1. Go to your repository: `https://github.com/Sanaznor71/sanaznor71.github.io`.
2. **Keep the `assets/` folder intact.** The HTML pages reference files within this folder.
3. Upload all five `.html` files and the entire `assets` folder to the root of `main`. GitHub's web upload interface can sometimes flatten folders; if that happens, use Git locally to preserve paths or upload the `assets` files into an `assets` directory in GitHub.
4. Under Settings → Pages, deploy from the `main` branch's `/ (root)` folder. The site URL is `https://sanaznor71.github.io/`.
5. Keep a backup of the previous `index.html` and `styles.css` until the redesign is verified.

## Add your real photograph

Replace `assets/portrait-placeholder.svg` with your photo file (for example `assets/profile.jpg`) and change the image source in `index.html` from `assets/portrait-placeholder.svg` to `assets/profile.jpg`. Crop roughly portrait orientation, ideally at least 800 × 940 pixels.
